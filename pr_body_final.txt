## 真实 E2E 覆盖（UI）

```
1.  Create Evidence (UI) — source_date 硬断言
2.  Edit Evidence (UI) — update body 无 subject 硬断言
3.  Create Thesis (UI) — 200 + revision v1
4.  Link Evidence (UI)
5.  Update stance (UI)
6.  Edit Thesis (UI)
7.  Revision diff (UI tab：起始/目标版本 +「对比」按钮；非假路由 /revisions/3/compare/4)
8.  Soft delete Evidence (UI only，无 API 回退)
9.  Archive Thesis (UI) — banner + 编辑/关联禁用
10. Duplicate archive → 409（API 读校验）
```
