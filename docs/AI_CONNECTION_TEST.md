# 手动检测 API 模型连接

在「设置 / 接入 AI」选择 API 接入，填写当前 Base URL、Model 和 API Key，然后点击「测试当前配置（可能产生费用）」。测试与保存是两个独立操作：可以测试尚未保存的表单值，成功也不会自动保存或同步后台凭据。

## 发什么、验证什么

- 只使用当前表单配置，发送服务端固定的一句合成测试文本
- 不读取持仓、账户、研报、研究笔记、对话历史或后台保存的模型凭据
- 不调用研究工具、不重试、不切换服务商、不自动保存结果
- 接收端由规范化后的同一个 URL 展示和请求；含反斜杠、控制字符、账号密码、查询参数或片段的含混地址不能用于检测
- 只有得到非空文本及完整流结束标记，才显示本次完成；HTTP 200、保存成功、登录成功都不等于完成
- 结果只证明这一组表单值完成了本次调用，不证明模型回答质量、工具能力、投资结论或之后一直可用

Codex 订阅及旧版 CLI 暂不支持这个有界探测，不会为了测试启动或登录 CLI。原有订阅功能不受此限制影响。

## 限额与费用

一次请求，向服务商请求最多 32 个输出 token；后端总等待预算为 15 秒，前端也会在 15 秒停止等待。响应正文、单行及文本有独立大小上限；压缩响应不用于本测试。网络清理有有限宽限期。

这些是客户端控制和请求参数，**不是金额上限或服务商停止计算/计费的保证**。取消、超时或服务商不遵守请求上限时，仍可能产生费用。具体由所选服务商决定。

服务商若不支持该限额字段或流式协议，测试会失败，不会偷偷去掉限额再试；这也不能独立证明普通聊天一定不可用。

## 取消与修改

测试中可取消。修改接入方式、模型、Base URL、API Key 或后端访问密钥，清除配置、切页，或收到配置更新事件，都会让旧结果失效；旧请求晚到也不能恢复成功标记。后端访问密钥修改后须先保存，再进行测试。

结果仅留在当前界面状态，不写 localStorage、不写投资数据库、不保存输入密钥或回答。错误为固定提示，不回显服务商原文。

## 验证边界

实现使用离线模拟 HTTP、ASGI 断连和前端状态测试，并由 CI 运行模拟浏览器流程。它不表示维护者已经用真实密钥测试了你的模型或端点。
