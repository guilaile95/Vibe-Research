# P0 runtime reliability preparation

Base: merged PR407, a61f31b7. External deployment reports are supplied evidence, not logs independently read from those hosts. No provider/model call or external service restart was made during implementation.

- Overview, valuation and THS financial endpoint provider work runs in a spawned process, with a 12-second work budget and bounded kill/reap cleanup. Four concurrent workers maximum per backend process; duplicate active keys return unavailable immediately. Results are read only after the worker exits, so an incomplete result write cannot hold the HTTP thread. Usable successes have a bounded 30-second parent cache; failure is not cached. A valuation quote checkpoint survives a slow optional forecast. This does not make every unrelated legacy provider endpoint deadline-bounded.
- Missing overview/valuation values remain null and explicitly unavailable. Financial failures identify the actual THS summary source and allow independently fetched quote rendering. HiThink/mootdx causes were not inferred from absent tracebacks.
- Daily review can retain an agreeing official-session date from identified Tencent index source timestamps. It never substitutes the server date, invents breadth, or relaxes refresh-quality gates. Explicit partial history still records its warnings; a missing source date remains unsavable.
- Connection testing permits at most one retry for a classified empty response, within the same 15-second budget and session. Partial/truncated content, malformed protocol, authentication, rate limits and cancellation are not retried. UI displays fixed safe error categories. Each attempt is capped at32 output tokens; a second attempt may also incur provider charges.
- The Linux launcher respects an explicit loopback VR_AGENT_RUNTIME_URL/PORT pair and uses the resolved port for child environment, port ownership checks and health probes. Default8911 remains. An environment variable must be set on the actual backend process at launch; setting a later shell variable cannot alter an already-running process. No Pi/Grok/AGY process was modified.
- PUT /api/portfolio/holding already exists; an absent holding yields404. DELETE uses query parameter code. No duplicate route was added. A deployment-specific pids.env file is not an application ownership authority and was not edited.

Acceptance: synthetic provider/process and API tests, source-date/history regressions, strict probe error/retry tests, production request-block tests and launcher mocks. Native Windows and actual browser acceptance require CI. Live-provider restoration is not established by these tests.
