### 2. 原理与技术路线

#### 2.1 速率代际与奈奎斯特频率

| 代际 | 单通道速率 | 调制 | 奈奎斯特频率 | 训练期内典型应用 | 来源 |
|---|---|---|---|---|---|
| 112G PAM4 | 112 Gbps | PAM4 | 56 GHz | NVIDIA HDR (800G 交换机)、IB NDR | 行业技术共识（OIF CEI-112G 标准） |
| 224G PAM4 | 224 Gbps | PAM4 | 112 GHz | 2025-2026 研发，下一代交换机/IB XDR | 行业技术共识（OIF CEI-224G 标准，分析推断） |
| 448G PAM4 | 448 Gbps | PAM4 | 224 GHz | 2026+ 早期研究 | 研究阶段（分析推断） |

- **关键原理**：PAM4 使每符号 2 bit，奈奎斯特 = 比特率/2；速率翻倍使可用带宽翻倍，但介质损耗（与 f 成正比）与导体粗糙度（趋肤效应 ∝ √f）使插损预算更紧，**直接推动材料等级与铜箔等级跳升**。（行业技术共识）

#### 2.2 插损（Insertion Loss, IL）预算

- **典型预算分配**（单通道 112G PAM4，训练期内共识）：总 IL 预算约 -25 ~ -33 dB（含封装、连接器、通道），其中 **PCB 通道 IL 通常 ≤ -1 dB/inch @ 奈奎斯特**量级；背板正交区间更紧。`[S?] 待补充 — 核验 NVIDIA 设计指南 / S05 Megtron 应用手册 / 行业白皮书`
- **IL 三导体**：介质损耗（∝ f，主因，Df 主导）+ 导体损耗（∝ √f，铜箔粗糙度主导）+ 阻抗不连续（玻纤/树脂界面、via stub）。**降低 Df 与降低铜箔粗糙度是两条主线**。（行业技术共识）
- **低粗糙度铜箔**：从 STD (Rz ~10-12 μm) → VLP (Rz ~6-8) → HVLP (Rz ~3-5) → HVLP2 (Rz ~2-3) → HVLP3 (Rz ≤ 1.5-2 μm)；**112G 普遍要求 HVLP2 及以上，224G 推 HVLP3**。（行业技术共识，具体 Rz 阈值以 IPC-TM-650 + 材料厂数据手册为准）

#### 2.3 介质 Dk / Df 要求

| 速率代际 | 典型 Df 上限（@1-10 GHz 量级） | 典型 Dk | 对应材料等级 | 来源 |
|---|---|---|---|---|
| 28G NRZ | Df ≤ 0.005 | Dk 3.3-3.7 | Mid-loss（Megtron 4 / Isola I-Tera / 生益 S6251） | 材料厂数据手册（公司口径） |
| 56G/112G PAM4 | Df ≤ 0.002-0.0035 | Dk 3.2-3.5 | Ultra-low-loss（Megtron 6 / Isola I-Speed / 生益 S7136） | 材料厂数据手册（公司口径） |
| 224G PAM4 | Df ≤ 0.001-0.0015 | Dk 3.0-3.3 | Super-low-loss（Megtron 7 / 陶瓷填充 PTFE 混合） | 材料厂数据手册（分析推断，核验 S-PANASONIC-MEGTRON/S-ISOLA/S-ITEQ） |
| 448G PAM4 | Df ≤ 0.001 以下 | Dk 3.0 以下 | PTFE / 特殊热塑 | 研究阶段（分析推断） |

- **Dk 与阻抗/传播速度关系**：Dk ↓ → 传播速度 ↑ → 同样介电厚度下阻抗更易控、损耗角优化；但 Dk 过低会加大玻纤/树脂界面失配风险。`[S_known_训练期]`

#### 2.4 树脂体系、玻纤布、石英布、PTFE 混合

- **树脂**：传统环氧 → 改性环氧 → PPO/PPE → 氰酸酯 → 苯并环丁烯 (BCB) → PTFE 热塑（低 Dk/Df 但加工难）。**112G 主流是 PPO/PPE + 改性环氧；224G 推 PTFE 混合或全 PTFE**。（行业技术共识）
- **玻纤布**：常规 E-Glass (Dk ~6.5) → 开纤布/扁平玻纤 (降低 Dk 波动、减少 skew) → 石英/熔融石英玻纤 (Dk ~3.7，配 PTFE)。**112G 普遍用开纤布；224G 推石英布**。（行业技术共识）
- **玻纤效应（Fiber-weave effect）**：高速下玻纤束与树脂的 Dk 差异导致 skew，开纤/扁平布是必要对策，**是高速板成本与良率的关键**。（行业技术共识）

### 4. 铜中板

- **定义**：铜中板（铜中板 / Midplane / Orthogonal Backplane）是 AI 机柜内位于机柜中部、**正交互联前后插拔板卡（GPU 板、交换板、I/O 板）的高多层高速背板**，通常无独立连接器、靠压接/背板插座直连，是 AI 机柜内**单块价值最高、技术门槛最高**的 PCB 之一。`[S?] 待补充 — 核验 S11 深南公告 + S16 + 行业白皮书`
- **形态**：训练期内 GB200 采用"铜中板正交架构"（NVL72 机柜中部铜中板 + 前后插拔 compute/switch 托盘）；GB300 延续并升级。`[S?] 待补充 — 核验 NVIDIA GTC 2025/2026 公开演讲`
- **技术门槛**：层数 30-60+、厚板（≥4-8 mm）、大尺寸（≥24×24 inch 级）、高厚径比（≥15:1）、无背钻或极少背钻、良率极低。`[S_known_训练期] 共识，具体阈值核验 S11/S16`
- **主要玩家**：训练期内公开口径涉及 AT&S、Unimicron、Kinwong、深南电路、沪电股份、Wus、Goldensun、方正科技等，**具体谁量产/谁入围未核验**。`[S?] 待补充 — 核验 S10/S11/S12/S13/S14 + S16/S17`
- **价值量**：训练期内传闻"单块铜中板数千至 1000+ 美元"，**未核验**。`[S?] 待补充 — 核验 S11/S16`

## 四、冲突信息 & 未确认问题
