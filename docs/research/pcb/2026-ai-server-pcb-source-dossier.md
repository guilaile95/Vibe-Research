## 分析推断

以下为信号完整性与产业链逻辑推演，**不是**已读标准或手册结论：

### 奈奎斯特频率（PAM4 / NRZ）

定义（分析推断）：

- NRZ：baud = bit_rate，Nyquist = baud / 2 = bit_rate / 2
- PAM4：baud = bit_rate / 2，Nyquist = baud / 2 = **bit_rate / 4**

| 代际 | 比特率 | 调制 | 波特率 | 奈奎斯特 |
|---|---|---|---|---|
| 28G NRZ | 28 Gbps | NRZ | 28 GBd | ≈ 14 GHz |
| 56G PAM4 | 56 Gbps | PAM4 | 28 GBd | ≈ 14 GHz |
| 112G PAM4 | 112 Gbps | PAM4 | 56 GBd | ≈ **28 GHz** |
| 224G PAM4 | 224 Gbps | PAM4 | 112 GBd | ≈ 56 GHz |
| 448G PAM4 | 448 Gbps | PAM4 | 224 GBd | ≈ 112 GHz |

**纠错说明**：不得把 112 Gbps PAM4 直接写成 Nyquist 56 GHz 而不区分波特率；正确为 56 GBd → Nyquist ≈ 28 GHz。

### 趋肤深度

纯铜、室温近似 δ = √(ρ/πfμ)；在 **56 GHz** 时铜趋肤深度约 **0.28 μm**（分析推断，未用材料厂手册核验）。

### 产业链与定价权

- 速率上升 → IL 预算收紧 → 材料/铜箔升级 → 认证壁垒抬升 → 可认证供应商收缩（分析推断）。
- 高端 CCL / 一线高速板厂相对更有定价权；通用多层与低端板厂更弱（分析推断）。
- 铜中板技术壁垒高、公开数据最少；延期信号可双向解读（分析推断）。

## 冲突口径

1. **市场空间**：不同机构预测区间跨度大；统计是否含 CCL、铜中板、交换板、电源板不一致。**本次不采用任何具体金额。**
2. **单柜 PCB 价值**：传闻量级跨度可达数倍至一个数量级；口径是否含铜中板/交换板不一致。**本次不采用。**
3. **224G 材料路线**：PTFE 混合 vs 陶瓷填充热固 vs 新一代 PPO 等路线未收敛。**保留冲突。**
4. **铜中板玩家**：多家被渠道提及，但谁量产/谁样品未核验。**保留冲突。**
5. **国内 Super-low-loss**：突破 vs 仍追赶两说并存。**待公告与材料手册。**
6. **奈奎斯特误用**：部分材料把 112G PAM4 直接写成 56 GHz Nyquist；本底稿按波特率修正为 ≈ 28 GHz。
