# AI execution remediation: P1-09 / P2-08 / P2-09 / P2-10

## Contracts
- One provider registry admits all nine API provider IDs and Codex. Native Intel preserves the supplied AI configuration rather than replacing it with freshness settings.
- Every model dispatch validates the server credential revision and complete configuration at admission. Browser preflight is advisory; the revision remains on the wire. Clear/replacement invalidates future dispatches, not already admitted calls. Only the explicit connection-test route holds an unforgeable in-process draft exemption.
- Configured, authenticated, dispatch-admissible, and model-connectivity-probed are distinct. Status/login never spends model tokens. Codex default model is `unknown/default`; no paid model is silently substituted. Unknown Codex results are never reusable model cache identities. API cache identities include provider, model, endpoint and revision through a non-secret digest.
- Python API calls share ModelTaskBudget and four execution slots, with 180-second overall deadlines, bounded calls/tools/output, sticky exhaustion, and ownership through cleanup. Node probes use bounded async spawn, singleflight and a two-second TTL. Node chat admission includes pending probes, cancellation and cleanup; output and wall time are capped. Runtime completion is published only after a clean terminal and EOF.
- DNS is resolved and all answers validated before admission; actual TCP connects the selected numeric address. Original Host, SNI and certificate hostname remain intact. Local mode supports loopback/private model and proxy endpoints, excluding metadata/link-local/unspecified/multicast addresses. Public mode requires public target and proxy addresses.
- HTTP and HTTPS models support direct, HTTP proxy and HTTPS proxy transports. CONNECT uses the validated numeric destination; TLS for both proxy and destination verifies the original names. Requests HTTPS-proxy/HTTP-target explicitly retains CERT_REQUIRED. NO_PROXY and CA bundle configuration remain honored; unsupported proxy schemes fail closed. Redirects are disabled. No OS network/security settings change.

## Verification and limitations
Synthetic regression coverage includes stale generations, a clear during DNS admission, unforgeable draft exemption, provider matrix, cache identity switches, metadata blocking, real Requests/httpcore protocol engines with fake TCP/TLS across 24 combinations, cancellation, budgets and terminal corruption. The Node suite injects probes and never runs a real CLI login/model. The browser fixture exports exerciseAiGeneration(browser); CI invocation is `node --import ./tests/e2e/runtime-env.mjs tests/e2e/ai-generation-remediation.browser.mjs` from frontend.

Real provider connectivity, actual Codex model resolution and hosted token accounting are not claimed. No real credentials, metadata services, proxies, models or login flows are accessed. Browser execution requires the existing CI Chromium fixture; source/unit checks are not a substitute. The HTTPX backend hook is isolated and tested against the repository-pinned dependency; upgrades must run the protocol matrix. Runtime identity is a once-captured startup snapshot, not an execution model identity.
